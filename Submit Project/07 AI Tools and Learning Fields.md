# AI tools and learning fields

## Which AI tools have you leveraged while working on this project?

We used OpenAI Codex to help research the problem, refine the architecture, write and review code, investigate errors, build tests and prepare documentation. We used built-in AI image generation for the original family poster and matching thumbnail, reviewing both before using them as promotional artwork.

For the walkthrough, we used ElevenLabs Sarah through OpenRouter for the approved narration, and ElevenLabs Scribe v2 through OpenRouter for transcription and word timestamps. We also auditioned OpenAI gpt-4o-mini-tts voices earlier, but those samples were not used in the final movie.

We kept those tools separate from the product runtime. Tonight Together's eligibility checks, explanations, negotiation and bounded feedback learning use transparent JavaScript rules. It does not depend on a remote language model to decide what a household should watch.

## Describe the level of learning you/your team derived from the project

Suggested selection: **Significant**.

Supporting explanation, if needed: We learned how to turn a shared-viewing problem into a revision-safe agreement workflow, verify a remote-first TV interface, coordinate independent participants and separate durable household memory from temporary sessions. We also developed a repeatable way to use AI assistance while checking code, media and claims against evidence.

## Did you gain AI value that you can use in your career?

Suggested selection: **Yes**.

Supporting explanation, if needed: We now have a reusable process combining AI-assisted development, testing, clear documentation, original promotional artwork and a narrated demo. The useful skill is knowing how to direct the tools, verify their output and preserve a workflow for another project.
