# Catalogue sources and data boundaries

Checked 20 October 2026. The application bundles the following real film metadata from Wikidata structured entities. Wikidata states that structured entity data is released under CC0: [licensing policy](https://www.wikidata.org/wiki/Wikidata:Licensing). This does not grant rights to the films, posters, clips, logos, or streaming services. None of those assets is included. All decorative visuals are original code-native shapes.

Source entity revisions and original claims are retained in data/catalogue-source-audit.json. Runtime filtering conservatively uses the longest recorded duration when versions differ; this is not a guarantee for every edition. Language fields describe source metadata, not verified streaming audio or subtitles. Mood tags and broad genre groupings are app-authored discovery aids, with animation also identified from source descriptions. Content exclusions, parental classifications and current availability are not inferred. Unknown required fields fail the matching check.

Sample mode uses 24 separately labelled project-authored illustrative entries and neutral sample viewers; those fixtures are not real programmes. Manually added records are household-entered, with explicit household content-review acknowledgement required before any exclusion coverage is treated as known.
