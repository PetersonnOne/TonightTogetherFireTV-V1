# Product decisions

The user selected the Household Consensus concept as the refinement of earlier viewing-companion research, and chose the name **Tonight Together**. This document preserves the decisions needed to understand this repository without requiring the original planning folder.

- Build a substantial household decision experience: individual fit, visible compromises, comparison, firm rejection, unanimous recorded agreement and reliable memory.
- Target Fire OS with an Android APK and validate on Android TV Emulator. Vega is outside this release.
- Keep the core local and independent of accounts, a backend or an LLM. Explain the actual deterministic scoring factors rather than generating persuasive reasons detached from the result.
- Distinguish choosing from watching. Only explicitly watched records influence the bounded fairness adjustment.
- Preserve boundaries when no title qualifies. Unknown content information cannot satisfy a firm exclusion.
- Keep real metadata separate from labelled illustrative fixtures. Never imply verified service availability, playback rights, or guaranteed suitability.
- Provide inspect, edit and deletion controls. Household members sharing the television can see the records; this is not confidential voting.

The [PRD](../Tonight_Together_PRD.md) defines the required scope. The [verification report](VERIFICATION.md) distinguishes implementation evidence from untested conditions. This repository does not claim household research interviews or measured time savings.
